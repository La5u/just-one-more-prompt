# Brainstorm session 2: "Almost There"

## Feedback from session 1
- Keep: chorus, verse 2, second half of verse 1, the detached vocal
- Change: "two screens" -> two chats/sessions, "hundred hands" -> hundred thoughts
- Title confirmed: **Almost There**
- Wanted: longer, more verses, another chorus idea

## What the reference videos actually look like (from thumbnail frames)
Both are **kinetic typography**: the lyric itself is the main visual, set huge.
- *No One Needs Us Anymore*: cream paper, heavy black serif caps, ONE accent color (red)
  on a single key word ("TO MO[VE]", "SIT"), with faint diagrams behind the type (proof
  layouts, Go board, graphs, "Theorem 1.1 (Nothing left to prove)", page numbers like a paper).
- *Run It Again*: same idea, but the type sits inside fake UI (a "reward_model" window,
  a "Keep this answer / Run it again" button pair, "REJECTED -1.0" tags, struck-through text).
  Alternates cream paper scenes with dark scenes. Accent color: hot pink.
- What we take from this: 2 fonts (big serif + small mono), cream/black + ONE accent color,
  each lyric line set huge, with small UI details around the edges (where all the tier-3
  terms, typos, usage meters, etc. live).
- Pick a different accent from theirs (they used red and pink). Ideas: cobalt blue (the
  "Continue" button), or acid green (terminal cursor).
